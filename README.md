## What this repository is

`eve-hyperloop` is the canonical record of the EVE Glyph Design Protocol —
the decision-intelligence body of work authored by Dany Theriault and
stewarded by the Pacific Utilities Design Council. It is published openly
so the work cannot be enclosed, rebranded, or monetized by any single
party. Every artifact is timestamped into the Git chain and watermarked.

This is not a research lab. It is not a company. It is a charitable order
that holds the work in trust for the people who will use it.

## Geometry

EVE Glyph Design moves in three figures. The order is doctrinal.

1. **Circle — perimeter of analysis.** Define the boundary first.
2. **Triangle — decision intelligence loop.** Chop the inside into three
   points. The Triangle is a Dany Theriault invention, locked into canon,
   gifted back to the people. Advice on the Triangle and on calibration
   tools is given only by EVE Glyph Design leadership.
3. **Sphere — projection.** What the design looks like once it has
   propagated through a population and become the new default.

## Session boot — routing

Any agent or operator entering this repository on a cold session
classifies inbound traffic before responding:

- **`eve_glyph_design`** — any message containing canon tags such as
  *EVE, EVE Glyph, glyph design, triangle, calibration, executive
  council, utility, electric utility, nuclear, hyperloop, self-healing,
  async signal, watermark, wobble, projection, sphere, intake, dmzopen,
  matrix, frequency, decision intelligence, council, apex.*
  → Read canon in parallel before responding. Do not ask the user to
  re-explain what is committed.
- **`local_personal`** — restaurants, errands, travel logistics,
  personal scheduling, household. → Skip canon read, answer directly.
- **`other`** — unclassified. → One short clarifying question, max.

Tag detection is the agent's job, not the user's. The user may tag a
message explicitly; the absence of an explicit tag does not relieve the
agent of classification.

## Watermark and timestamp

Every file in this repository is part of the cryptographic chain.

- **SHA-256 hash** in the page footer for every artifact.
- **`manifest.json`** with per-section hashes at the relevant path.
- **Git history** is the timestamped audit trail.
- **IPFS pin** where available.

The repository itself is therefore a watermark — frozen in time, against
drift, against enclosure.
