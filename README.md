## What this is

EVE Hyperloop is the wireframe for a children's educational video game built
around three shapes and three lessons:

1. **Circle** — find the edge of a problem.
2. **Triangle** — make a choice with three good reasons.
3. **Sphere** — see the lesson belong to everyone.

The public landing page at [`index.html`](./index.html) is the wireframe
itself. Everything else — design notes, contributor materials, governance —
lives in private mirrors and is shared by request.
