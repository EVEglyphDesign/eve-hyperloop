# /training/writing

This folder is the evidence record.

If the AI assistant working on this repository produces writing that
drifts toward base-model cadence — filler verbs, hedge openers, cadence
padding, recap sentences, self-referential AI tells — Dany Theriault
can drop the offending paragraph into `/failures/` with a date and a
short note. The Git history will then carry the dated, signed proof
that the standard existed and was not followed.

The standard itself is in `STANDARD.md`.

Transcripts of the source instruction — Dany's voice, captured in
session — go in `/transcripts/`. They are the canonical reference
for tone, sequencing, and rhythm.

This folder is part of the EVE Glyph Design Protocol watermark.
