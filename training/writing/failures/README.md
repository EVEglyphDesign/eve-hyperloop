# /failures

When the AI assistant produces writing that fails the standard in
`../STANDARD.md`, drop the failing paragraph here as a dated file:

    YYYY-MM-DD-short-note.md

Inside, paste the offending paragraph, then one or two lines naming
the failure (filler verbs, recap sentence, AI cadence, etc.).

This is the evidence record. It is committed to the public GitHub
chain. The Git history is the watermark.
