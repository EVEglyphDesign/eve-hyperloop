# Visual Cortex vs. Left/Right Brain — Primer
Source: ARK Queue 2026-05-20, Thread A (captured verbatim payload)

## Visual cortex — specialized region
Located in the occipital lobe at the back of the brain. Processes vision in a hierarchy:
- **V1 (primary)** — edges, orientation, contrast, motion direction
- **V2–V5** — shapes, color (V4), motion (V5/MT), depth
- **Dorsal stream** ("where/how") → parietal lobe, spatial location, guides action
- **Ventral stream** ("what") → temporal lobe, object and face recognition

The visual cortex exists in **both** hemispheres. Each side processes the *opposite* visual field — optic nerves partially cross at the optic chiasm.

## Hemispheric lateralization — which side leans which way
Most right-handed people:
- **Left hemisphere** — language (Broca, Wernicke), sequential/analytical, arithmetic, logic, right-side motor
- **Right hemisphere** — spatial reasoning, face recognition, prosody, holistic pattern, left-side attention, left-side motor

Pop-psych "left = logic / right = creative" is a **myth**. Modern neuroimaging shows nearly all complex tasks recruit both hemispheres via the corpus callosum. Lateralization is real but subtle.

## Two orthogonal axes
| Axis | What it describes |
|---|---|
| Visual cortex vs. other regions | Functional specialization by region |
| Left vs. right hemisphere | Lateralization — which side a function leans toward |

Reading a sentence: visual cortex (both hemispheres) sees the text → left hemisphere language areas decode meaning.
