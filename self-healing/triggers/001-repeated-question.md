# Trigger 001 — Repeated question

## Signal

Agent asks the user a question whose answer is already present in canon
(`glyph.html`, `individual.html`, `council.html`, prior transcripts,
memory).

## User reactions that fire this class

- "I already told you that"
- "Don't make me repeat myself"
- "That's in the transcript / in the canon / in memory"
- "I am the human here. You are the machine. You are supposed to know."

## Root cause

Sequential processing. Agent narrates a plan and asks for direction
instead of reading canon and proceeding.
