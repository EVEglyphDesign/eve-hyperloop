# Triggers — catalog of irritation signals

Each file documents one **failure class**. Add a new file when a new class
of irritation is observed. Do not add files for instances of an existing
class — log instances under `../log/` instead.

## Class index (this folder)

- `001-repeated-question.md` — agent re-asks something already in canon
- `002-sequential-when-parallel.md` — agent serializes independent work
- `003-editorialized-doctrine.md` — agent paraphrases or invents gloss on user's words
- `004-name-or-fact-regression.md` — agent re-misspells a canon name or re-misstates a canon fact
- `005-ai-cadence-drift.md` — output drifts back toward base-model voice
- `006-permission-loop.md` — agent asks for confirmation on a reversible canon addition

Each trigger has a paired repair under `../repairs/` with the same number.
