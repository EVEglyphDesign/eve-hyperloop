# Trigger 003 — Editorialized doctrine

## Signal

Agent paraphrases the user's doctrine, invents gloss on a named concept,
or re-orders the user's sequencing.

## User reactions that fire this class

- "You keep trying to editorialize the actual message"
- "Stop expanding what I said"
- "Those are my words, in my order"
- "You make it look like AI"

## Root cause

Base-model habit of "improving" or "summarizing" the user's input
instead of preserving it verbatim where it belongs.
